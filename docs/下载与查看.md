## 看过后的判断

它与当前需求很接近：在原生“^”面板中显示文件夹，点击进入，再返回顶层。配置规则决定图标归属，支持应用名称、提示文本和辅助功能名称匹配；不能靠拖入文件夹完成分类。

实现上复用原始图标数据对象，重新组织面板显示列表；通过 Windhawk 对系统托盘模块的内部函数挂钩。它不是独立运行的 EXE。

作者说明测试过 build 26300，与本机主版本相同。这是积极线索，但不等于本机 `26300.9711` 已验证。

源码含卸载恢复列表和清理事件订阅的逻辑，也明确处理了清理失败情形。静态检查不能证明正常退出、异常退出及 Explorer 重启都可靠。

建议用它做实际分组体验的基线；我们后续主要可改进可视化选图标分组的体验。技术路线仍待实测后定。

## 实际试用入口

1. 运行上面的 Windhawk 官方安装包，完成 Windhawk 安装。
2. 在 Windhawk 中查找 **System Tray Folders**，核对作者 **Ris Peng** 及插件 ID `system-tray-folders`。
3. 安装模块，在设置中添加一个文件夹和对应应用名称规则。
4. 点击任务栏“^”，检查文件夹及原图标的单击、双击和右键菜单。
5. 停用模块后检查原始图标是否恢复。
